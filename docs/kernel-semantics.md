# 核の意味論（v0）

形式ツールを束ねる記述体系の、文法から独立した意味論。正本は参照評価器（`crates/idealis-semantics/src/reference.rs`）で、この文書はその説明。各検査器と写し方は、参照評価器との差分テストで同じ意味であることを示す（[0097](../evals/plans/0097-rmodel-reference.md)）。文法はまだ決めない。

## 値と範囲

- **sort**: 検査ごとに大きさを決めた、有限のatomの集合。enumは名前の付いた、ちょうど1つずつのatom。すべてのatomは互いに異なる。
- **関係**: atomのtupleの集合。単項（集合）と二項。
- **型**: 式の型は「sort Sの集合」か「sort Aからsort Bへの二項関係」で、静的に検査する（[0099](../evals/plans/0099-sorts-and-violations.md)）。和・差・積と比較は両辺が同じ型、joinは繋ぐsortが同じ、代入は変数と同じ型でなければ型エラー。`none`はどの型にも合う。sortの違う集合を混ぜる式は書けない。
- **和のsort**: `type Party = Person + Org`は子のatomの和で、自分のatomを持たない。子は和の部分型で、同じ和の子どうしの和・比較は和の型を持つ（[0100](../evals/plans/0100-sum-sorts.md)）。
- **整数の算術**は正確に評価する。型検査では中間式を含めて符号付き64ビットに収まるかを保守的に調べる。TLA+ 変換では対象の数値範囲でも確認する。両方とも範囲の確認を通ったモデルだけを検査する。状態や引数を列挙する `scope Int` は別に指定する。[算術の静的検査](../crates/idealis-syntax/src/numeric.rs) · [オーバーフローの回帰試験](../crates/rmodel/tests/values.rs)
- **値**（[0103](../evals/plans/0103-values.md)）: `Int`、`Bool`（`true`と`false`のenum）、`record Money { amount: Int, currency: Currency }`。値はatomではなく構造で等しい。関係は値を1つ（`one`）か高々1つ（`lone`）持ち、値の集合は宣言できない。scopeの`Int = lo..hi`は、初期状態・引数・recordで数え上げる整数。遷移が範囲の外の値を作った状態は探索せず（組み込みのcheck `Scope`の違反）、探索は完全でなくなる。witnessのないcheckは未確定になる。値のsortは量化しない。
- **算術**: 両辺がInt型の`+`・`-`・`*`は算術。被演算子と整数の比較（`<`など）は、静的に値が1つに決まる式（literal、`#`、束縛変数、`one`の単項の関係、値が1つの式の`one`の関係・fieldのjoin）に限る。空になりうる`lone`の値は型エラーで、実行時の部分的な演算は起きない。
- **部分的な演算**（0での除算、空の集合からの選択など）: 未定義のエラー。そこへ至るtraceをwitnessとして報告し、偽や空に読み替えない。

## 構造と状態

- **設定**: 状態とともに変わらない関係（`rel`）への割り当て。型（定義域の部分集合）と多重度を満たし、`fact`を満たすものすべてを考える。
- **状態**: 変わる関係（`var`）への割り当て。初期状態は型・多重度と`init`を満たすもの。
- **遷移**: actionと引数の値の組ごとに、条件が成り立つとき、代入の右辺を現在の状態で評価して次の状態とする。代入しない`var`は変わらない（暗黙のframe）。
- **更新の違反**を調べるときは、まず保存値が探索範囲に入るかを見る。範囲から出ると `Scope` 違反になる。範囲内で多重度または保存値の `data ... where` を破る更新は `Declarations` 違反になる。違反を起こす更新は組み込み検査の経路に残し、通常の状態検査は合法な到達状態を対象にする。[型と範囲を分ける回帰試験](../crates/rcheck/tests/data_types.rs)
- **呼び出し**: 定義（predicate・関数・action）の呼び出しは、引数の式を本体に代入する。値として渡さない。

## 問いと結果

- `invariant`: すべての設定で、到達できるすべての状態で成り立つか。
- `reachable`: ある設定で、初期状態から条件を満たす状態に到達できるか。初期状態自身も候補とする。`transition ... on 操作` は、有効なその操作の前後を比較する。
- 結果は用語集（[glossary](glossary.md)）の語で返す。
  - **complete**で探した範囲で: 成り立つ・破れる・到達できる・到達できない。
  - **bounded**: 上限の中で反例・到達がないだけで、完全な検査ではない。
  - **empty**: `fact` を満たす設定と、その設定で `init`・型・多重度を満たす初期状態の組が一つもない。
  - **unreachable**: 初期状態が存在するが、調べた範囲に到達条件を満たす状態がない。Alloy/SAT の到達性検査は候補がないとき、同じ範囲に初期状態があるかを残りの予算で確認する。確認できなければ `unknown` を返す。[検査器間の照合](../crates/rcheck/tests/registry.rs)
  - **unknown**: 予算が尽きて判定を出せない。
- 破れる・到達できるの判定には、最短の深さとwitness（trace）を付ける。witnessは参照評価器で検査し直せる。

## まだ決めていないこと

- 時相の性質の意味（無限のtrace・lassoか有限のtraceか）とfairness。
- sortの大きさを「まで」にする書き方（部分集合で表すか）。
- 設定を1つに固定する問いの書き方。
- bool・record・map・列などの値。
