# 0119 自然文と遷移の対応を追う

発送済みの状態と追跡方法を維持する SHIPMENT-TRACKING を試す。全案で同じ発送モデルと性質を使い、モデル検査とは別に、自然文と式の対応を人が承認する場面を扱う。

| 案  | 比較する構造                                                                                                   |
| --- | -------------------------------------------------------------------------------------------------------------- |
| A   | 現行に近い要件 ID と性質名の参照。判定は性質全体に付ける。                                                     |
| B   | ProR の変更追跡を参考に、要件文・参照する性質の版を承認時に保存する。                                          |
| C   | Event-B の事例で前提・要求ごとに根拠を追うように、適用範囲と二つの節を明示し、節ごとに式とレビューの版を持つ。 |

固定の対照は、正常、意味を保つ言い換え、追跡方法の変更を許す文章、式から追跡条件を外す、操作が追跡方法を書き換える、リンク切れ、モデルコメントのみの変更。モデルと式の検査は rmodel の参照評価器で実行する。B/C のレビュー版はテキストの内容と参照式の正規化 IR を見て判定する。同義でも編集は要再確認。操作の変更はモデルの証拠を失効させる。実行時の読み取り資料に今回の故障対照を反映する。

独立した代理読み手3人に A/B/C の資料を異なる順序で提示する。採点対象は、文章だけの変更後のリンク、モデル検査、レビューの状態と、保留になる範囲。読みにくい箇所、最初に調べる場所、好みの理由も取得する。参照先の確認に使う技術資料として扱い、通読時間は計測しない。3人の読解の観察を採用判断の材料にする。人への一般化は行わない。
