# 0124 実測から採用のゴール証拠を作る

rprob の 3×4 の辺探索を、参照評価器と同じ release バイナリ内で比較する。パースと lowering を一度済ませた prepared モードで、一プロセス4評価、ウォームアップ1回、5標本。測定前に候補の評価版、バイナリとモデルの SHA-256、ホストの種別、実行条件を計画に保存する。モデルの判定は測定前に一致を確認する。

各方式の壁時計時間について、標本の幅が中央値の20%より大きい場合は未測定とする。候補の最大値が比較元の最小値より10%以上小さければ改善。候補の最小値が比較元の最大値より10%以上大きければ悪化。それ以外は改善なし。上限と下限は今回の標本の範囲として扱う。

自己モデルでは同じ計画、有効で安定した標本、改善基準の達成をすべて要求する。各条件を外した故障を検出する。実装では旧計画、別の実行モード、異常終了、欠落、ノイズの大きい標本、改善なし、悪化、改善を区別する。採用判定は現在版の意味比較と節レビューも引き続き要求する。
