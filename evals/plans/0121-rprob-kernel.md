# 0121 有限集合モデルの探索カーネル

rmodel の型検査済み AST を入力に、集合と二項関係を整数ビット列で評価する rprob を試作する。型の名前解決と操作の引数展開を探索の前に済ませる。幅優先探索で、参照評価器と同じ判定、最短深さ、宣言違反、操作の到達、予算切れを比較する。参照評価器は判定の oracle として残す。扱えない構文やスコープは明示して拒否する。

固定の入力は既存の権限・セッション・排他モデル、追跡方法を関係で表した発送モデル、二項関係に辺を追加・削除できる密な探索例。正常、追跡方法の上書き、Courier の確認を禁止、空、探索予算切れを区別する。反例の深さと探索予算の単位を比較する。

macOS arm64 の release ビルドで、パース・準備を各実行に含めた反復と、同じパース済みモデルでの探索反復を別に計測する。prepared の rprob は lowering を一度済ませる。参照側はパース済み AST から各回評価する現行 API を使うため、探索ループだけの差には帰属しない。各比較で各 checker の判定が一致することを先に確認し、time wall と分散を記録する。計測の主比較は権限 fixture と 3×4 の辺探索、4×4 は拡大時の参考とする。
