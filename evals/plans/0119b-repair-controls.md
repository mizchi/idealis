# 0119b 証明・検査を通すために振る舞いを消す対照

Event-B Agent の §4.4 と §5.5 を読んだ後、発送モデルで修正の採否を区別する短い追試を追加する。0119 の読み手の資料・問い・採点条件はそのまま使う。

同じ性質 ShippedStays を固定し、追跡方法を書き換える故障に対して、確認操作をすべて止める案、Courier だけを止める案、上書きだけを除く案を比較する。正常版の挙動を要求する対照として、Courier と Post それぞれで発送して確認済みとなる状態が到達可能かを調べる。性質が成立し、二つの到達例が揃う場合を、この固定有限モデルの採用条件とする。モデルの意味が変わるため、確認ができることは要件側が保持したい挙動として先に固定する。
