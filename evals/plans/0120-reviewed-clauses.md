# 0120 要件の節を名前付きの検査へ結ぶ

0119 の C 案を rspec に接続する。既存の要件全体の claim に加え、節は要件内の ID、日英の本文、名前付きの claim、任意の対応レビューの版を持つ。自然文や式を読む人が版を記録する。CLI は現行版の識別子と、モデルを再検査した結果を出す。未リンク・未確認・要再確認・判定なしを区別する。

発送で固定するのは発送状態の維持、追跡方法の維持、Courier と Post の確認済み状態への到達。正常版、文だけの編集、式の編集、リンク切れ、操作ガードだけの変更、モデルのコメントだけの変更、探索予算切れを比べる。節の文と式の対応を検査した記録は、対象の版を変更すると失効する。操作だけの変更では対応レビューを維持し、モデル判定は毎回取り直す。要件の共通文・用語・形式側の宣言や仮定は版に含める。人が確認した対応と参照評価器の判定を同時に見られる出力にする。
