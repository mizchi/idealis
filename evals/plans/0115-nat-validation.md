# 0115 整数、Nat、処理前のモデル検証

有限列挙の範囲は `scope Int = lo..hi`。Nat はそのうち0以上の値とする。計算に使う整数の範囲は列挙範囲と分け、参照評価器が符号付き64ビット、TLA+ への出力が移植可能な符号付き32ビット。算術の上下限を型検査した木から保守的に計算し、表現できない演算を成立として扱わない。Nat への格納で負になる遷移と宣言範囲から出る遷移は `Scope` として観測する。既存の Int の引き算は整数の引き算を保つ。

処理前の検証は、操作の JSON の型・数値範囲、設定の事実、初期状態、先行操作の再生、現在のガード、遷移先の宣言と範囲を段階的に調べる。処理を実行しない validation と、成功時だけ処理を呼ぶ接続例を用意する。正の操作、負の Nat、範囲外、ガード偽、Nat への負の更新、64ビットでオーバーフローする例を対照にする。
