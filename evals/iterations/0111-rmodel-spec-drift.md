# 0111 自然言語の仕様から文法の検査を回す

[計画](../plans/0111-rmodel-spec-drift.md)に沿って、[自然言語の仕様](../../spec/rmodel-design.pkl)に採用条件、改版、具体的な状態遷移を書いた。rmodel のモデルと実装テストをつなぎ、[意思決定ログ](../../crates/rmodel/grammar-decisions.md)から見られるようにした。

| 確認                   | 結果                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 規則とモデル           | rspec の参照・生成物の検査に合格。rmodel の参照評価器で採用条件8件、入れ替え例4件の判定が仕様と一致した。                             |
| モデルと実装           | 構文比較・採用判断の6テストに合格。条件を外す対照と改版後に古い証拠を残す対照を拒否した。改版の前後は具体トレースのテストで検査した。 |
| 自然言語の意味の drift | Jev が3件の比較を選んだ。モデルを固定して採用条件の文章だけを反転すると、比較入力のハッシュが変わった。                               |
| Jev のライブ判定       | OpenRouter の認証が HTTP 401 で拒否され、通常版は3件とも判定なし。文章を反転した対照のライブ判定も未取得。                            |
| ゴールの測定           | `behavior` の読みやすさは未測定。採用判断は評価中。                                                                                   |

`just rmodel-design-write` で仕様の表示とモデルへの参照を生成する。`just rmodel-design-check` で機械的な検査を回す。`just rmodel-design-drift` は生成物を確認してから意味の比較に進む。生成した Markdown だけを変更した対照は、Jev の起動前に D6 で拒否した。ライブ判定の欠落は未検査として扱う。

## TypeSafe API での再実行

`TYPESAFE_API_KEY` を使い、`jev-1.14.0` で通常版と文章だけを反転した対照を検査した。通常版では3件すべて判定を取得し、`--replay` で3件とも同じ判定を再現した。[通常版の判定台帳](../../.jev-lint/judgments/rmodel-design/20261125T135905691Z-47dd0f58.jsonl)

| 規則               | 通常版               | 文章を反転した対照   |
| ------------------ | -------------------- | -------------------- |
| `RMODEL-SEMANTICS` | 支持 0.84            | 矛盾 0.82            |
| `RMODEL-GOAL`      | 支持 0.98            | 支持 0.98            |
| `RMODEL-SWAP`      | 矛盾 0.51、支持 0.47 | 支持 0.52、矛盾 0.44 |

値は Jev が返した各判定の確率。反転した採用条件は矛盾と判定された。変更していない入れ替え規則は2回で判定が割れた。モデルの `update` は遷移前の値で評価され、二変数の入れ替えと、代入していない変数の保持を rmodel の参照評価器と回帰テストで確認した。この例の仕様とモデルの不一致を示す反例は確認できなかった。読みやすさの判定は別途評価する。
