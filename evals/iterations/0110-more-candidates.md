# 0110 候補の追加と絞り込み

[計画](../plans/0110-more-candidates.md)と[実行設定](../plans/0110-more-candidates.json)に従い、権限、口座、注文、セッション、サービスの5題材に5候補を追加した。候補ごとに別の書き手がモデルと検査手順を用意した。「実装への接続」の採点は、各候補の実測と公式に提供される機能の両方を含む。

| 追加候補                                                                   | 検査と制約                                                                                                                |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| [Souther](../experiments/surface-languages/souther/README.md)              | 38件の実行例と JVM クラス生成を確認。注文を直和型で表現できる。5箇所の不変条件は実行時の検査が残った。                    |
| [Koine](../experiments/surface-languages/koine/README.md)                  | C# と TypeScript を生成してコンパイルし、C# で5題材の操作を実行した。外部実装との照合と活性は未計測。                     |
| [Context Mapper](../experiments/surface-languages/contextmapper/README.md) | CML 5件の宣言を検査。集約、関連、多重度、ライフサイクルを表現した。値に依存する業務ルールは操作宣言とコメントで補った。   |
| [FizzBee](../experiments/surface-languages/fizzbee/README.md)              | 固定した有限のモデルを探索。サービスの9状態で弱い公平性を入れた活性を検査し、公平性を外すと反例を検出した。               |
| [P](../experiments/surface-languages/p/README.md)                          | 各題材で固定 seed の256スケジュールを検査し、サービスの対照で待ちが残る反例を検出した。弱い公平性のある無限経路は未計測。 |

Haiku は週次上限で起動できなかった。読みやすさの回答は予定24件のうち0件で、12候補とも未測定。

初回の一括実行は共有の `JAVA_HOME` に Java 21 を指定したため、Souther 0.5.0 のクラスをロードできなかった。初回結果は作業領域に保存し、モデル、採点、問いを固定したまま OpenJDK 27.0.1.1 で別の run を実行した。

## 結果

[OpenJDK 27 での成績表](../runs/0110-more-candidates-java27/scorecard.md)の12候補すべてで、候補ごとに定義したツールチェーンの検査が通った。[初回の検査結果](../runs/0110-more-candidates-development/checks.json)も保存した。宣言の検証、実行例、有界探索、有限探索はそれぞれ上の表に示した範囲で通過している。

計画の閾値を丸める前の得点に適用した。

| 役割               | 残す候補               | 根拠                                                                                                              |
| ------------------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 表の構文           | Isabelle、Pkl、Souther | DDD記述 0.80 以上、機械での理解容易性 0.75 以上                                                                   |
| 検査器             | Quint、Pkl、FizzBee    | 木の評価 0.75 以上で、サービス題材に対する活性の答えがある。Quint と Pkl の活性の根拠は 0107 の評価を引き継いだ。 |
| 実装への接続の参考 | rmodel、Souther        | 生成、照合、強制のルーブリック平均 0.75 以上                                                                      |

追加候補の中では Souther と FizzBee が次の比較に残る。Souther は DDD記述 0.86、機械での理解容易性 0.75、実装への接続 0.83。FizzBee は DDD記述 0.57、木の評価 1.00 で、弱い公平性の有無に応じた活性の判定が得られた。Koine、Context Mapper、P、既存の OCaml、Idris 2、Veil は今回の閾値を満たさなかった。この絞り込みは比較対象の選定まで。

Context Mapper の行数が最少だったが、宣言とコメントに留まる操作があり、行数の差は表現した振る舞いの量も含む。既存の IR 照合は rmodel が5題材、Pkl が4題材で一致した。新規5候補の idealis IR への adapter は今回追加していない。

入力78ファイルのハッシュを照合し、保存した run の複製に対して `just surface-eval-score` を再実行した。JSON と Markdown の成績表はどちらもバイト単位で一致した。0109 も保存済みの結果から再採点し、7候補の5軸の値が一致した。
