# 0117 遷移前後の検査と読み取り

[事前条件](../plans/0117-transition-readability.md)に従い、実行可能な操作の前後に `transition` を適用した。明示的な no-op は検査し、暗黙の待機は含めない。空のモデル、探索の打ち切り、スコープ逸脱は成立に数えない。

| 対象       | 結果                                                                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 出荷       | 正常版では成立した。確認操作が追跡方法を上書きする故障は、参照評価器、rtlc、TLC のすべてで2遷移目に検出された。処理前の validator はコールバックを呼ばなかった。 |
| 待機       | 状態が変わる操作だけのモデルでは成立した。到達できる明示的な no-op を加えると、参照評価器と rtlc の両方が2遷移目で違反を検出した。                               |
| Pkl の注文 | `ShippedStays` の照合を IR に載せ、参照評価器と rtlc で成立を確認した。先行状態で束縛したペイロードは、後状態のタグとペイロードに分けて比較する。                |

出荷と再試行について、`before(...)` / `after(...)` とプライム表記は、型検査後の IR と参照評価器の判定が一致した。各題材の判定は3件。TypeSafe の認証がこの環境にないため、事前に設定した本比較は未測定。

二人の独立した代理読み手に各題材3問を出した。読み手Aは出荷を明示表記、再試行をプライムで読み、読み手Bには割り当てを逆にした。前後の読み方は両者に同じように教えた。各表記6問中6問正解。どちらも前後、適用範囲、値の保存を読み取れた。試行が少なく、表記の優劣は判断できない。人間の読み手は未測定。[回答と根拠](../runs/0117-transition-readers/observations.json)

`just rcheck-transition` と `just rmodel-transition-tlc .artifacts/0117-replay` で検査を再実行できる。読み取りの本比較は `just rmodel-readability-eval .artifacts/0117-live transition` を、認証が入っている環境で実行する。[設計判断](../../crates/rmodel/grammar-decisions.md)
