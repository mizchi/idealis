# rprob の対応範囲

ProB の集合・関係モデルに着想を得た試作。入力は rmodel の構文。

- [x] 型検査済みの rmodel の有限 atom、列挙、和 sort、集合、二項関係をビット列に落とす。和・差・積集合、直積、関係の join、等値・包含、多重度、要素数の比較、有限量化を扱う。
- [x] 構成の事実と初期条件、ガードと並行代入を評価する。不変条件、到達可能性、前後の状態を使う遷移性質、宣言違反、操作の到達を探索する。
- [x] 空、予算切れ、完了、最短の違反・到達深さを区別する。予算は参照評価器と同じく構成、初期候補、到達状態を数える。対応外の入力にはエラーを返す。
- [x] 集合のみのモデルは全型の合計64 atom、二項式を含むモデルは8 atomまで。set / some の候補ドメインは20 tupleまで。one / lone は単項で atom、二項で各行の合法な選択を列挙する。引数展開には別の上限がある。
- [ ] 整数を状態に保持するモデル、record、列、値付き variant、時相・公平性の問い。
- [ ] ProB の入力形式と制約ソルバー、Event-B の refinement 証明、反例の全操作列。
